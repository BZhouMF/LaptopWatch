LaptopWatch - 局域网文件管理器 / LAN File Manager

一个基于 Flask 的轻量级跨设备文件共享工具，通过桌面 GUI 快速搭建局域网文件服务，支持电脑、手机、平板等设备通过浏览器访问和管理文件。

## 主要功能

- **四种运行模式**：普通文件管理、视频模式、图片模式、抖音式滑动播放
- **密码保护**：访问密码认证，保障内网数据安全
- **在线预览**：图片画廊/幻灯片、视频播放（自动生成缩略图）、文本查看（代码高亮）
- **抖音模式**：上下滑动切换视频、手势控制亮度/音量/快进、倍速播放、预加载
- **目录浏览**：卡片式分类展示，按文件夹分组，惰性分页
- **文件操作**：单文件/批量下载、文件夹 ZIP 打包下载
- **管理后台**：独立 Web 控制面板（端口 5001），一键启停服务、日志监控、定时关机
- **响应式设计**：适配手机、平板、电脑各种屏幕
- **桌面 GUI**：Tkinter 控制面板，二维码扫码访问
